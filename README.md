# EaglecraftX 1.8.8

An iPadOS-focused EaglercraftX 1.8.8 client.

## Target Features

- Minecraft 1.8.8
- iPadOS support
- Magic Keyboard support
- Trackpad/mouse support
- 60 FPS maximum
- Fullscreen support
- iPad Files app skin importing
- iPad Files app texture-pack importing
- Local browser storage
- Touch-control fallback
